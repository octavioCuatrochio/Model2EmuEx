# Geometry processor (TGP) commands: `t <command> <name> <what it does>`.
# The i960 sends command c by storing to c*16(g11), and its parameters
# to 0x4000+(g11); results are read back from 0x4000+(g11). Confirmed
# against the traffic by tools/tgpmodel.py (notes/geometry.md).
t 02 mul                (a, b) -> a*b
t 03 div                (a, b) -> a/b
t 05 push               push the current matrix
t 06 pop                pop the current matrix
t 0a atan2              (x, y) -> angle of (x, y), 16-bit
t 0f angle_to           (x1, z1, x2, z2) -> angle from point 2 to point 1
t 10 identity           current matrix = identity
t 11 get_matrix         -> the current matrix: 3x3 column by column, then the translation
t 12 translate          (x, y, z), in the current frame
t 13 scale              (sx, sy, sz)
t 14 rotate_x           (angle): rotate by minus the angle about x
t 15 rotate_y           (angle): about y
t 16 rotate_z           (angle): about z
t 1a transform          (x, y, z) -> the point through the current matrix
t 1b sin                (angle) -> sin
t 1c cos                (angle) -> cos
t 1d mul_sin            (angle, r) -> r*sin
t 1e mul_cos            (angle, r) -> r*cos
t 24 acc_load           accumulator = x
t 25 acc_get            -> the accumulator
t 26 acc_add            accumulator += x
t 27 acc_sub            accumulator -= x
t 28 acc_mul            accumulator *= x
t 29 acc_div            accumulator /= x
t 31 set_quad           four (x, y, z) corners: a car's footprint
t 32 in_quad            (x, y, z) -> -1 if (x, z) is inside the quad, else 0
t 40 set_circle         (x, z, r)
t 41 circle_dist        (x, z) -> distance from the circle's edge
t 43 distance           (x1, z1, x2, z2) -> distance between the points
t 44 polar              (angle, r) -> (r*sin, r*cos)
t 47 step               (angle, d, x, z) -> (dx, dz, x+dx, z+dz), dx = d*sin, dz = d*cos
